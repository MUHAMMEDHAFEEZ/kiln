# Kiln brand

The mark is a rounded diamond filled with three bands of terracotta whose edges are gentle ridges:
fired clay, layered paper, mountains. The files here are generated by [`tools/make-brand.py`](../../tools/make-brand.py),
so they stay exact; change the script, not the images.

| File | Use |
|---|---|
| `mark.svg` / `.png` | The symbol on any dark or mid background (transparent) |
| `mark-2layer.svg` / `.png` | The symbol at 24 px and below (favicons, tray icons) |
| `mark-cream.svg`, `mark-dark.svg` | One-colour symbol: ridges become thin gaps |
| `app-icon.svg` / `.png` | App icon: the symbol on a rounded square |
| `app-icon-2layer.svg` / `.png` | App icon for small sizes |
| `app-icon-sizes.png` | How the icons look at 256 to 16 px |
| `lockup-light.svg` / `.png` | Symbol + "Kiln" for dark backgrounds |
| `lockup-dark.svg` / `.png` | Symbol + "Kiln" for light backgrounds |
| `social-preview.png` | GitHub social preview, 1280 × 640 |
| `banner.png` | README banner, 1600 × 420 |
| `avatar.png` | Square avatar, 800 × 800 |

## Colours

| | Hex | Use |
|---|---|---|
| Terracotta | `#d97757` | main accent, middle band |
| Light terracotta | `#e8a088` | top band, highlights |
| Deep terracotta | `#b5573a` | bottom band |
| Background | `#1c1b19` | dark surfaces |
| Card | `#24221f` | cards, panels |
| Cream | `#ece6da` | text on dark, light surfaces |

## Rules

* Keep clear space around the symbol of at least a quarter of its width.
* Use the three-band mark from 32 px up and the two-band mark below that.
* Do not recolour the bands, add shadows or gradients, or stretch the symbol.
* The wordmark is set in Ubuntu Bold (Ubuntu Font Licence), converted to outlines in the SVG files.
